# 🚀 Astro Relic

**Explore Space. Discover Worlds. Learn Through Stories.**

Astro Relic is an interactive 3D space exploration and educational experience designed to make learning about space exciting and accessible for children.

Inspired by planetary science and space exploration, Astro Relic combines immersive visuals, storytelling, interactive activities, and guided discovery to help young explorers learn about our Solar System and the mysteries of Mars.

## 🌌 Key Features

- 🪐 **Interactive 3D Solar System** — Explore planets and discover the wonders of our cosmic neighborhood.
- 🔴 **Mars Exploration** — Learn about Mars through guided exploration and educational storytelling.
- 🤖 **Rover Missions** — Discover historic Mars exploration missions, including Mars Pathfinder and the Sojourner rover.
- 🧑‍🚀 **Nova, Your Space Guide** — Follow a friendly guide on a journey through space.
- 📖 **Story-Driven Learning** — Discover scientific concepts through engaging stories and interactive experiences.
- 🌍 **Bilingual Experience** — Support for Bengali and English learning experiences.
- 🎮 **Interactive Activities** — Encourage curiosity through exploration and hands-on discovery.

## 🎯 Our Mission

Our mission is to make space science more engaging for children by combining interactive technology, storytelling, and educational exploration.

Astro Relic encourages young learners to ask questions, explore new worlds, and discover the science behind space missions.

## 🚀 Getting Started

### Prerequisites

- Node.js (a current LTS version is recommended)
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/morsalin-rifat/astro-relic.git
   ```

2. Navigate to the project directory:

   ```bash
   cd astro-relic
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 🌟 Why Astro Relic?

Space exploration can inspire the next generation of scientists, engineers, and explorers. Astro Relic aims to turn curiosity into discovery through an accessible, interactive, and story-driven learning experience.
